# Crop Recommendation Using Machine Learning 🌱

## Project Overview
This mini project uses Machine Learning to recommend suitable crops based on soil nutrients and environmental conditions.

## Problem Statement
The objective is to predict the most suitable crop using agricultural parameters such as Nitrogen, Phosphorus, Potassium, temperature, humidity, pH, and rainfall.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- Decision Tree Classifier

## Project Workflow
1. Data Collection
2. Data Exploration (EDA)
3. Data Preprocessing
4. Feature and Target Separation
5. Train-Test Split (80:20)
6. Model Training
7. Model Evaluation
8. Crop Prediction

## Model Evaluation
- Accuracy Score
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Input Features
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

## Target Variable
Crop Label

## Conclusion
This project demonstrates how Machine Learning can help recommend suitable crops based on soil and environmental conditions.
